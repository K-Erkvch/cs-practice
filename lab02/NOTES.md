Рабочая папка - это директория, где Git отслеживает изменения
Индекс - промежуточная область перед коммитом.
Коммит - зафиксированное состояние проекта в истории
Git - это локальная система контроля версий на компьютере.
GitHub - это облачный сервис для хранения репозиториев Git и совместной работы.
git diff - показывает разницу между рабочей папкой и индексом
git diff --staged - изменения уже в индексе, готовые к коммиту
Использованные команды:
-git status: показывает состояние рабочей директории и индекса
-git commit: сохраняет изменения в файле.
-git diff: показывает разницу между рабочей директорией и индексом
-git diff --staged: показывает различия между индексом и последним коммитом
Ветки:
Ветка - это независимая линия разработки. При новом коммите указатель ветки сдвигается на новыйкоммит. Слияние (merge) объединяет изменения из одной ветки в другую
