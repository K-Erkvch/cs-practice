## Чем отличаются git diff, git show и git log

- **git diff** — показывает разницу между двумя состояниями (например, между текущими правками и последним коммитом, или между двумя коммитами). Показывает только сами изменения: строки с `+` и `-`.
- **git show** — показывает информацию об одном конкретном коммите: автора, дату, сообщение и изменения, которые в нём были.
- **git log** — показывает историю всех коммитов по порядку (от новых к старым). С флагом `--stat` дополнительно показывает, какие файлы менялись и на сколько строк.

## Что нашли команды log -S и blame

- **git log -S"Вычитание"** — нашёл коммит `5758f05` ("Update calc.py 'Buch'"), в котором впервые появилась строка со словом "Вычитание". Команда ищет коммиты, где добавлялась или удалялась указанная строка.
- **git blame lab03/calc.py** — показал, кто и в каком коммите написал каждую строчку файла. Строки 1-2 появились в коммите `f044d61` ("Create calc.py"), строка 3 — в `5758f05`, строки 4-5 — в `df09b14` ("Umno").
