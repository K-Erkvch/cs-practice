## Чем отличаются git diff, git show и git log

- **git diff** — показывает разницу между двумя состояниями (например, между текущими правками и последним коммитом, или между двумя коммитами). Показывает только сами изменения: строки с `+` и `-`.
- **git show** — показывает информацию об одном конкретном коммите: автора, дату, сообщение и изменения, которые в нём были.
- **git log** — показывает историю всех коммитов по порядку (от новых к старым). С флагом `--stat` дополнительно показывает, какие файлы менялись и на сколько строк.

## Что нашли команды log -S и blame

- **git log -S"Вычитание"** — нашёл коммит `5758f05` ("Update calc.py 'Buch'"), в котором впервые появилась строка со словом "Вычитание". Команда ищет коммиты, где добавлялась или удалялась указанная строка.
- **git blame lab03/calc.py** — показал, кто и в каком коммите написал каждую строчку файла. Строки 1-2 появились в коммите `f044d61` ("Create calc.py"), строка 3 — в `5758f05`, строки 4-5 — в `df09b14` ("Umno").
## Чем отличается git restore от git restore --source=...

- **git restore lab03/calc.py** — отменяет незакоммиченные изменения в файле, возвращая его к состоянию последнего коммита (HEAD).
- **git restore --source=HEAD~2 lab03/calc.py** — берёт версию файла из конкретного коммита (в данном случае из HEAD~2) и делает её текущей рабочей версией. Это как "машина времени" для одного файла.

## Что произошло бы с моими правками?

Если бы я не выполнил `git restore` после порчи файла, удалённые строки так и остались бы удалёнными в рабочей папке. Если бы я закоммитил их, они попали бы в историю. `git restore` просто стирает незакоммиченные изменения, как будто их и не было.

## Чем тег отличается от ветки

- **Тег (tag)** — это **постоянное имя для конкретного коммита**. Тег `v1.0` навсегда указывает на тот коммит, где проект был в рабочем состоянии. По тегу версию находят и через полгода, и через год. Теги не двигаются.
- **Ветка (branch)** — это **подвижный указатель** на последний коммит в цепочке. Когда ты делаешь новый коммит в ветке `main`, указатель `main` автоматически сдвигается вперёд. Ветка — это «живая» линия разработки, а тег — это «застывшая» метка версии.
